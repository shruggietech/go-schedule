# Quickstart: S103

1. Open Notifications in the running desktop app and enable native desktop popups. Grant OS permission if requested.
2. Choose conditions, severity, and registered daemon scope; save the desktop-local setting.
3. Produce a new matching terminal task run or alert. Expect one concise OS popup, with no older history replayed.
4. Activate the popup on a platform that supports response callbacks. Confirm it opens the exact Activity record on the expected daemon, or presents a safe stale-target message.
5. Disable or silence popups and produce another event. No new popup should appear. Close the app and confirm no closed-app delivery is promised.
6. Inspect the v1.5.0 release draft: it may describe native popups but must leave SMTP and the broader notification epic deferred and open.
