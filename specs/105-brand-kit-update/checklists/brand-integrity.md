# Brand integrity checklist: S105

**Purpose**: Check the brand release and repository adoption design before implementation

- [x] Formal release archive and SHA256SUMS identify one exact package
- [x] Brand and BrandBuilder versions are recorded separately
- [x] Official migration contract identifies the approved current mark

- [x] Repository consumers and retired copies have explicit ownership
- [x] Linux packaging and Windows icon fallback have defined migration paths
- [x] Docs web manifest base path is handled explicitly
- [x] Source integrity and attended native appearance are reported separately
