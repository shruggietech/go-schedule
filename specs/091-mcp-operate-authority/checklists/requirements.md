# Requirements Quality Checklist: MCP Operate Authority

- [x] Observe remains the default and has no tools.
- [x] Operate exposes exactly three bounded task actions.
- [x] Daemon, task, and request identity are explicit.
- [x] Actor attribution and intent-first audit are required.
- [x] Revocation semantics cover existing connections.
- [x] Duplicate and uncertain outcomes are specified.
- [x] Execution inputs and secrets remain excluded.
- [x] Remote MCP, Manage, and durable grant administration are excluded.
- [x] Every requirement is testable without an unstated product choice.
