# Quickstart

Run `sh scripts/verify.sh automation` for integrated maintainer contracts, or `sh test/scripts/maintainer-commands_test.sh` for the focused native command corpus. Run `sh scripts/verify.sh all` for the normal full delivery aggregate. The existing `automation-check_test.sh failure-propagation` mode delegates to the isolated driver guard. These commands validate source tooling, not an installed application or published package.
