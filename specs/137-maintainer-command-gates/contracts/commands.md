# Command contract

The canonical list remains format, vet, lint, race, gui, coverage, docs, automation in that order. Automation retains its current policy and coverage checks and additionally invokes the shared maintainer-command corpus. The same focused corpus runs under Bash on every existing native test platform.

Both public wrappers inspect explicit absolute, caller-relative and caller-default roots literally. Success must identify the target fixture, including one lifecycle specification, rather than merely return zero. The driver guard copies production source without test switches and stubs all expensive child roles. Early failure status 37 and its stderr survive; no later child runs. A deliberately broken-stop copy is rejected without running real gates.
