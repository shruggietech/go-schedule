# S114 data model

No production persistence or public report schema changes. Investigation observations preserve source/input/runtime identity, native outcomes, bounded phase/launcher details and independent causal disposition. Release handoff binds the pending version and later source/tag/run/attempt/release/candidate/asset/checksum identities without inventing absent public records.

Issue state progresses to delivered only for a demonstrated correction or supported upstream disposition. An unknown original cause stays open, even when the investigation and source PR are complete.
