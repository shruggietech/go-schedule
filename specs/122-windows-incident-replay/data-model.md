# S122 investigation data

Campaign: version 1, source commit/content digest, input executable hashes, runtime identities, planned conditions, common start/deadline, completion or interruption and cleanup.

Condition: track, baseline, storage, scenario/test name, repetition, expected outcome and selected interpreter/prerequisite identity. Runtime observations also identify writer/session literal and incident ID. IPC observations identify catalog ID and component versus packaged execution.

Observation: original native exit/output, assertion results, command/inspection/protocol/collection/cleanup fields, phase/time, incident path/hash and remaining resources. Expected negative results remain expected; unavailable collection remains independent.

Disposition: hypothesis, supporting matching observations, contradictory observations, causal conclusion or uncertainty, separate defect/fix/upstream reference and affected source identity. States are planned, running, observed, failed, unavailable or interrupted; a completed campaign does not imply a corrected original issue.
