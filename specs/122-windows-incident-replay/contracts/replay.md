# Bounded investigation contract

Maintainer replay is opt-in, uses existing test entry points and does not change public CLI or the version 1 full-QA report. Private Go test JSON and incident files are supporting evidence, not a replacement full-catalog qualification.

The fixed report sections are: Source and limits; Planned and observed matrix; Runtime/prerequisite outcomes; IPC/inspection outcomes; Causal findings and corrections; Cleanup and unresolved outcomes. Every matrix row names condition/repetition, expected/actual original outcome, exact identities, incident reference and cleanup. A missing or failed collection never rewrites original outcome.

Run no more than ten repetitions per selected condition and use one common thirty-minute campaign execution deadline, recording early stop, omitted conditions and independent verification separately. Do not reset the deadline per group. Use fresh private workspaces, exact executable identities and existing collector bounds. Never use synthetic test-host process identity for process termination.
