# Contract: MSI Summary Subject

## Approved value

`go-schedule: cross-platform task scheduler`

## Source contract

- WiX `SummaryInformation Description` equals the approved value.
- The value contains no U+2014 character.
- All unrelated package and product identity remains untouched.

## Compiled contract

- Windows Installer Summary Information PID 3 equals the approved value.
- Evidence includes the observed Subject and SHA-256 of the inspected MSI.
- A missing, unreadable, or mismatched Subject fails inspection.

## Native observation boundary

Explorer tooltip or Properties observation is native evidence. Source and compiled inspection support it but do not impersonate it.
