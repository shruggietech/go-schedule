# Preparation contract

`go run ./scripts/windows-qualification-session --manifest ABSOLUTE_JSON --output ABSOLUTE_NEW_DIRECTORY` verifies identities and bytes, rejects overlap/reparse/occupied destinations, and produces separate fresh and upgrade Sandbox configurations. Preparation never executes supplied software or alters GitHub. Host paths are XML data; guest filenames are fixed.

The bootstrap refuses outside Sandbox, stages verified inputs to local disk, prepares offline prerequisites, and opens intentional attended MSI UI with flushed logs and diagnostic progress. Upgrade first installs the independent baseline and pauses for representative-state preparation. Timeout preserves state and forbids subsequent operations until reset. Evidence remains unavailable until explicitly reviewed through the existing collector and gate.
