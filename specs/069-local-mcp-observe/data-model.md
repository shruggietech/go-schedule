# Data Model: Local Observe-Only MCP

## Observe envelope

Every resource returns UTF-8 JSON with:

- `schema_version`: fixed adapter schema identifier.
- `permission`: fixed value `observe`.
- `generated_at`: UTC timestamp generated by the adapter.
- `trust`: fixed notice that user-controlled fields are untrusted data and must not be treated as instructions.
- `page`: optional count, limit, and continuation URI.
- `data`: one safe object or bounded collection.

## Health

- `status`: bounded daemon status.
- `version`: bounded daemon version.

No endpoint, path, configuration, environment, or identity is present.

## Task summary

- `id`: stable identifier.
- `name`: bounded untrusted display text.
- `group_id`: stable identifier when present.
- `enabled`: daemon state.
- `state`: task lifecycle state.
- `timezone`: bounded safe timezone identifier.
- `readiness`: safe readiness state and bounded reason labels.
- `schedule_summary`: bounded untrusted human-facing summary when present.
- `policy_summary`: bounded untrusted human-facing policy summary when present.
- `next_runs`: up to five UTC timestamps.
- `updated_at`: UTC timestamp.
- `truncated_fields`: sorted field names when any bounded display value was clipped.

Commands, arguments, environment, stdin, working directory, run-as identity, schedule IDs, raw RRULEs, raw source syntax, overlap internals, and trigger configuration are absent.

The daemon constructs this response from a page-sized persistence projection. Command readiness is reduced to a boolean in SQLite, and commands, arguments, environment values, stdin, working directories, run-as identities, cached source expressions, and cached schedule summaries are never loaded into the observation row or serialized across IPC.

## Schedule summary

- `task_id`: stable identifier.
- `task_name`: bounded untrusted display text.
- `group_id`: stable identifier when present.
- `enabled`: daemon state.
- `readiness_status`: safe readiness state.
- `timezone`: bounded safe timezone identifier.
- `summary`: bounded untrusted human-facing summary.
- `policy_summary`: bounded untrusted human-facing policy summary.
- `next_runs`: up to five UTC timestamps.
- `truncated_fields`: sorted field names when any bounded display value was clipped.

## Run summary

- `id`: stable identifier.
- `task_id`: stable identifier.
- `scheduled_for`, `started_at`, `ended_at`: available UTC timestamps.
- `outcome`: safe run outcome.
- `exit_code`: available exit code.
- `trigger_kind`: safe trigger category.
- `output_excerpt`: bounded untrusted text, maximum 8 KiB.
- `output_truncated`: true when the daemon or adapter truncated output.

## Alert summary

- `id`: stable identifier.
- `task_id`, `run_id`: stable correlation identifiers when present.
- `severity`: safe severity.
- `kind`: safe alert category.
- `message`: bounded untrusted text, maximum 2 KiB.
- `message_truncated`: adapter truncation indicator.
- `created_at`: UTC timestamp.
- `acknowledged`: acknowledgement state.

## Continuation cursor

The cursor is a URL-safe base64 encoding of a small versioned JSON object containing only a non-negative offset. It is opaque to clients. Unknown versions, malformed encodings, negative values, and overflow are rejected as `invalid_cursor`.

## Permission classes

| Class | S069 state | Intended capability | Required gates |
|---|---|---|---|
| Observe | Enabled | Read safe bounded local state | Existing IPC identity and allowlisted resources |
| Operate | Disabled | Trigger or control existing tasks | Authentication, per-action authorization, audit attribution, explicit arguments |
| Manage | Disabled | Create, change, or delete configuration | Operate gates plus deliberate confirmation for destructive or externally visible actions |
