# Data model: S116

## Timeout policy

Each boundary has a scope, former allowance, selected allowance and classification. All numeric values and preserved contracts are in contracts/timeouts.md. No product persistence or authority model changes.

## Selected QA run

Budget identity is default, supplied complete override or original resume identity. Execution total and case limits are immutable for a captured run. New cleanup/reporting reserves belong to the selected executable policy; resume queries the original executable. Source/binary/runtime hashes and exact command/inspection/cleanup outcomes bind current observations.

## Release handoff

Source commit and content digests identify preparation. Tag, release ID and package hashes are absent until separately authorized staging. Public selection staysv1.5.1. Original unresolved issues remain open on individual functional outcomes.
