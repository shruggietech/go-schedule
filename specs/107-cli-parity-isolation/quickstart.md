# S107 local qualification guide

Use owned disposable daemon state and invocation dependencies. Never substitute the installed service or real user persistence. Exact reviewed commands/results are recorded in verification.md.

1. Run focused CLI/API regressions for environment clears, set/clear conflicts, disabled creation, hierarchy and complete preview requests.
2. Exercise heterogeneous notification export/reapply, invalid/duplicate requests and inheritance reset against fixture state.
3. Exercise preference migration/concurrent scoped edits, invalid-input byte preservation and startup-profile choices without network/native secrets.
4. Start an owned packaged daemon with unique IPC/config/data; validate identity/PID/contained paths before mutation, execute benign input and inspect calendar/active/exact runs.
5. Exercise recording service/GUI handlers, cancellation and independent invocation roots.
6. Observe fixture systems with successful and unreachable/mismatched targets; retain successes and independent failures within bounds.
7. Run `sh scripts/verify.sh all` in the hidden foreground launcher to completion, then `go run ./scripts/github-format` and `git diff --check` before local commit.

This focused qualification is not the future full Windows/WSL evaluator/report product.
