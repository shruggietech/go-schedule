# S143 quickstart

Use an owned disposable daemon and hidden test executables. Run gosched runs active to obtain an exact current Run ID, then gosched runs cancel RUN_ID (or --json). Expect requested until authoritative active/history observation reports canceled or explicit cleanup failure. Cancel one of two same-task concurrent fixtures and keep the other alive. Repeat the same ID after completion and expect its existing terminal result.

The desktop Activity Run details exposes the same Cancel run action for the selected daemon and execution. Headless fixtures cover pending, actual canceled result, failure/unconfirmed state, identity switches, observer refusal and keyboard activation without operator focus.

Focused regressions cover native parent/child process termination and native-result races; #466 supported API negotiation; #467 concurrent skip/queue behavior; local/remote authorization, CLI/MCP and durable history. Existing Windows/WSL adapters and macOS CI supply platform-specific execution. Run sh scripts/verify.sh all in the foreground for final source acceptance. This is source implementation, not an installed-product, release or attended-native-UI claim.
