# Qualification records

- Candidate: repository, tag, reviewed revision, staging run and attempt, installer filename, bytes, and SHA-256. All identities must agree.
- Backup: old annotated tag object and target, release metadata, complete old assets and local hashes. Retained separately from new sessions.
- Session: fresh or upgrade, candidate and independent baseline identities, environment, phase logs and unavailable templates.
- Observation: existing collector schema, scenario, actual result, measurements and independently validated attachments. No inferred success.
- Handoff: evidence identity, limitations, review dispositions and latest-head checks. Qualification-complete and public-release states remain distinct.
