## Outcome

Reject watcher path bindings for unknown bundle identities. A misspelled binding is silently ignored, hiding a portability error.

## Authority, parent and source

Parent: #277. Discovered by the owner-authorized full S108 evaluation for #289 and #290. This is a product correction against pending source 57461fcf350967f9b50cc9d999a0d6c84ada8411 with dirty=true, version gosched version 0.0.1-dev; it is not a claim about a published release.

Relevant implementation: [internal/cli/bundle.go](https://github.com/shruggietech/go-schedule/blob/57461fcf350967f9b50cc9d999a0d6c84ada8411/internal/cli/bundle.go), [internal/bundle](https://github.com/shruggietech/go-schedule/blob/57461fcf350967f9b50cc9d999a0d6c84ada8411/internal/bundle).

## Bounded scope

bundle preview accepts --watcher-path=missing=ABSOLUTE_PATH even when the bundle has no matching watcher and produces a usable plan.

## Reproduction

1. Prepare the source and six Windows/Linux inputs identified by S108 run 0f1e9217-fd59-4f0e-bee9-f9c1d8d441a3.
2. Use the owned S108 fixtures, with an existing Windows user and an explicitly selected existing WSL2 distribution/nonroot user. The [execution guide](https://github.com/shruggietech/go-schedule/blob/8522df934ac46e3b45067d78d98f66c82372ce17/docs/cli-qa.md) supplies the standard command and boundaries.
3. Inspect windows/bundle.watcher-bindings and wsl/bundle.watcher-bindings, or repeat the exact redacted argv against only the corresponding owned fixture. Use recording host adapters for service/GUI operations and disposable credential/profile stores.
4. Compare the observed result below with the required behavior. Full affected references are in finding F005 of the canonical report.

## Expected and actual behavior

Expected: Every supplied watcher binding resolves to one watcher in the selected bundle.

Actual: bundle preview accepts --watcher-path=missing=ABSOLUTE_PATH even when the bundle has no matching watcher and produces a usable plan. Representative expected/observed exit: 2/0.

Impact: A misspelled binding is silently ignored, hiding a portability error.
