## Quick reference

- Governing principle: familiar scheduling, explicit behavior.
- Mode: dark-first. Night `#071014`, Panel `#0D171C`, Line `#28414B`, Paper `#F6F8F7`.
- Accents: Interval Mint `#62D9B7`, Anchor Blue `#58A6FF`, Hold Amber `#F2B84B`, Stop Red `#E05F5F`. Use the deeper light-surface variants defined in `tokens/brand.tokens.json` for text on Paper.
- Type: Space Grotesk 500/700 for display, Geist 400/500 for body, Geist Mono 400 for schedules, paths, logs, and metadata.
- Voice: practical, exact, calm. State timezone, catch-up, overlap, and daemon behavior when they matter. Avoid productivity hype and calendar jokes.
- Logo: terminal prompt, command line, and five schedule cells. Use the reduced mark at 32 px and below. All distributable SVG typography is outlined.
- Cover and guide artwork: use the transparent mark directly on the page surface. Do not place a square logo tile on a slightly different background.
- Accessibility: status always includes text or shape; every interactive element has a visible 2 px focus ring; respect reduced motion.

For static visual artifacts, link `styles.css` and `components/components.css`. For production code, copy only the required tokens and components.
