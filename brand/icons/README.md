# go-schedule icons

Six starter icons use a 24-unit grid and a 1.5-unit stroke: calendar, clock, terminal, repeat, play, and history. They inherit `currentColor` from the surrounding component.

Extend the set with direct scheduling, task, service, and history symbols. Keep strokes between 1.5 and 2 units, use modest rounding, and avoid decorative calendar art or alarm-clock imagery.
