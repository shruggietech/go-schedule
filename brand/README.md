# go-schedule brand 2.0.0

The official go-schedule brand kit is the pinned `go-schedule-brand-2.0.0-bb2.4.0.zip` archive in this directory. The archive contains the complete source guide, asset inventory, licenses, design tokens, platform exports, and BrandBuilder build evidence. Its SHA-256 and formal release URL are recorded in [`source.json`](source.json).

The current primary mark is the compact prompt and cursor geometry. The previous framed terminal and cron-field mark is retired. The product palette and typography remain governed by the official kit. Use the archive's `README.md` and `brand-guide.pdf` for the complete visual rules; use [`REPOSITORY.md`](REPOSITORY.md) for this repository's import and consumer workflow.

The files beside the archive are selected, checked consumer copies for the application, documentation, and packages. [`repository-consumers.json`](repository-consumers.json) declares their provenance. Run `go run ./scripts/brand-check` after an update to verify the archive and every declared copy.
